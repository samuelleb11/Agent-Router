Accounts

A fresh claude setup-token value, if the current one was revoked or you want to rotate it. The account keeps its id, so everything already recorded against it stays intact.

Copied from your claude.ai browser cookie. Used only to read usage — it is never sent to api.anthropic.com and never signs a request, and it lives in a separate Keychain entry from the credential that does.

Run claude setup-token in a terminal that is logged into the other account and paste the sk-ant-oat01-… value it prints. A sk-ant-sid… session key copied from claude.ai is a browser cookie, not an API credential, and will not authenticate.

The router runs claude setup-token for you and issues a long-lived (1-year) credential, so it never needs refreshing. Sign in as the account you want to add — not the one you are already using.
